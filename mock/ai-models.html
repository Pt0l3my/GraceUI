Models

Each job EldenNet gives a model has its own slot: a provider, a model and a fallback. A preset sets them all at once.

How to use it

  1. Pick a preset and Apply it, or set a slot by hand.
  2. Each slot’s fallback is used while its provider cools down.
  3. Budgets (tokens, time limits, retries) are fixed: the same in every preset.
  4. Prepared lines can be made ahead at rest, so fights need no live calls.
